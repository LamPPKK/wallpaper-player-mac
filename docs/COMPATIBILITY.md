# Background Engine compatibility

| Type | Mode | Notes |
|---|---|---|
| Video | Full Live or Full Cached | AVFoundation-compatible streams play directly. Other valid local MP4/MOV/WebM/MKV/AVI content is probed and converted atomically by bundled FFmpeg 9.0.1 using VideoToolbox H.264/AAC. A recognized VideoToolbox session failure retries once with the bundled native MPEG-4/mp4v encoder. An odd frame dimension is scaled up by at most one pixel; FFmpeg adjusts sample aspect ratio to preserve display aspect ratio. The cache identity includes the conversion recipe, and a legacy cache remains playable while it is flagged for a safe source rebuild. |
| Web | Full Live, Limited, or Unsupported | Project-root files only, non-persistent storage, property callbacks, local autoplay, and pause callbacks. Navigation/download/native bridge are blocked. External network is opt-in. Audio-reactive wallpapers receive neutral data and are Limited. The probe reads the complete entrypoint within its aggregate budget, analyzes executable inline script/style blocks and template-literal expressions, and follows reachable local static ES-module imports and CSS `@import`. Script `src` and inline bodies participate only for executable/default/module script types; JSON, import-map, speculation-rule blocks, and classic `nomodule` fallbacks remain inert on the macOS 14 module-capable Web runtime. Only local `.js`/`.mjs` modules are parsed recursively, while other local literal specifiers are validated for existence and project-root containment. Missing/escaping dependencies are Unsupported with `web_local_dependency_missing`, while required HTTP(S) dependencies are `web_network_access_required` until permission is granted. Cycles terminate through canonical-path deduplication; exceeding the 2,000-node or document-element, 8 MiB text, or 256-reference-per-file limits fails closed with `web_dependency_probe_limit_exceeded`. These paths prevent a blank WKWebView from being presented as Full. |
| Image/GIF/APNG/WebP | Full Live | ImageIO playback preserves per-frame timing, decodes on demand under memory limits, and supports Fit, Fill, or Stretch. |
| Scene | Full Live, Full Cached, Limited, or Unsupported | Native playback is preferred when all required capabilities are supported. The GPL renderer creates a 20-second 30 FPS crossfaded MP4 cache otherwise, preferring VideoToolbox H.264 and using MPEG-4/mp4v only for a classified encoder-session failure. SceneScript interaction and audio-reactive behavior are Limited. Authored sound and the final stream are verified; each MP4 is published under an immutable generation URL with a size/SHA-256-bound sidecar. Provably corrupt required packaged model, material, or texture data is Unsupported with `scene_required_asset_unreadable`; unresolved package paths remain renderer candidates because stock files may come from the user-provided engine-assets tree. Missing audio, corrupt metadata, or a stale generation preserves visual playback but records `sound` as missing with `scene_authored_audio_unavailable`. |
| Windows Application | Unsupported | Recognized but never launched through Wine or CrossOver. |

Scene compatibility claims apply only to the legally owned external corpus used for release testing. Every item receives a versioned compatibility report and a stable diagnostic code; intentionally dark or static frames are warnings, not hard failures. Release acceptance requires the app, XPC service, screen saver, Scene renderer, FFmpeg, and ffprobe to build and smoke-test on Apple Silicon and Intel. Real Workshop content stays outside Git.
